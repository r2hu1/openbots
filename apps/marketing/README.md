# OpenBots Marketing (`apps/marketing`)

The public-facing marketing and landing website for OpenBots.

## Overview

- High-performance marketing pages and product showcases.
- Shared UI design language and components using `@openbots/ui`.
- Theme management via `next-themes`.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **UI & Styling**: React 19, Tailwind CSS v4, `@openbots/ui`, `next-themes`
- **Linting & Formatting**: Biome

## Scripts

```bash
# Start development server (port 3002)
bun run dev

# Build for production
bun run build

# Start production server
bun run start

# Code formatting & linting
bun run lint
bun run format
```
