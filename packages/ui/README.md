# `@openbots/ui`

Shared component library and design system for OpenBots web applications.

## Overview

- **Design System**: Built on Tailwind CSS v4 and Base UI primitives (`@base-ui/react`).
- **Avatar Engine**: Integrated Blobatars dynamic avatars (`@blobatar/react`, `blobatar`).
- **Rich Interactive Components**: Embla carousel, OTP inputs, command palettes (`cmdk`), Lucide & Tabler icon integrations, toast alerts, dialogs, and 3D canvas support (`@react-three/fiber`).

## Usage

```typescript
import { Button } from "@openbots/ui";
```
